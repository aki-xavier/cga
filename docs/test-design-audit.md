# 测试设计审计（第一性原理）与修复记录

状态：**修复完成（2026-10-09）**。本文档是审计报告 + 修复台账。审计范围：26 个文件、338 个 `#[test]`（修复前计数）。

## 审计标准（从项目文化推导）

- **P1 闭式断言优先**：期望值必须来自独立数学，不得与被测实现同源（自我金标 = 循环论证）；交叉验证只允许以独立验证过的件当裁判（FD / 第三方解析器 / 已验证 API）。
- **P2 确定性**：无未固定种子、无时间/环境依赖，逐位断言优先。
- **P3 诚实边界覆盖**：Err 文本、Unknown/拒绝/退化路径必须有断言。
- **P4 公差纪律**：闭式解 1e-9 级；松公差必须有推导或注释来源。
- **P5 断言强度**：不等式取可证最强形式；杜绝"永不失败"的断言。
- **P6 独立性**：无顺序依赖、无全局状态泄漏。
- **P7 退化/边界覆盖**：0 / 奇异 / 对跖 / 反向 / 限位。

### LM 语义改进（V4 连带）

修 V4 时发现真问题：`lm_solve_j` 把"收敛到非零残差的驻点"报成"LM 停滞"——法方程右端 b = −Jᵀr 本身就是驻点度量，但代码没用它区分。改进：停滞时先查 |b|∞ < 1e-7·(1+|r|)（与 `newton_minimize` 收敛口径同尺度；解析 J 与残差两条求值路径在驻点上仍有 ~1e-8 噪声，实测定标）⇒ 驻点返回 Ok，由调用方终检给出「目标不可达 / 机构装不上」的准确语义；|b| 显著非零才是真停滞。闭链侧同步受益（"机构可能装不上"取代笼统"未收敛"）。

**副产物（裁判自身的限度）**：acos 在 θ→π 奇异（dθ/dc = −1/sinθ 发散），FD 在该区域先天受损（实测相对误差 3e-4）——奇异点邻域的正确裁判是代数恒等式（J_l⁻¹·J_l = I，J_l 用独立闭式实现），不是 FD。已写入 `rotvec_left_jac_inv_is_exact_inverse_near_antipode` 的注释。

## 灰色（系统性四类，修复原则）

1. **无推导公差 + 硬编码期望值**（`cga-mesh/bake.rs` 最重）：体积断言 5–19% 公差无推导、期望写 `4.18879` 而非 `4π/3`。**已修**：期望值全部闭式化（4π/3、π/12、2π²·0.09、π/3、4π/3−1），公差加统一的误差模型注释（边界层 ≈ 表面积·步长，抵消后实测远小于界；公差是截断/退化回归看守不是精度声称）。
